# Typing Master – Offline Typing Practice App

**Created by:** Priya Kumari

## About the Project
Typing Master is an offline-friendly typing practice application designed to help users improve their typing skills in both English and Hindi.

## Features
- English Typing Practice
- Hindi Typing Practice
- Typing Lessons
- Typing Tests
- Story-based Typing Practice
- Typing Speed (WPM)
- Accuracy and Mistake Tracking
- Simple and User-Friendly Interface

## Purpose
I created this project to help beginners improve their typing speed, accuracy, and confidence through regular practice.

## Technology Used
- HTML
- CSS
- JavaScript

## How to Use
1. Open the website link.
2. Select Hindi or English typing practice.
3. Choose a lesson or test.
4. Start typing and track your progress.
